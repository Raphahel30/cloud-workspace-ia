# Backup da direção artística R03

Destino verificado: https://drive.google.com/drive/folders/1GrIR0r9C0qY7KrHli1HFFbmvFLUqiql0 .

O pacote ZIP contém os arquivos individuais versionados de direção artística e os quatro registros canônicos, além do relatório histórico R02. Pode ser extraído mantendo os caminhos `docs/codex/` para abrir a comparação HTML com imagens locais.

- `MANIFESTO_ORIGEM.json`: caminhos, tamanhos e SHA-256 locais do conteúdo, sem incluir a si próprio ou o ZIP no cálculo.
- `RECIBOS_DRIVE_INICIAL.json`: metadados observados após a primeira gravação de nove arquivos.
- `RECIBOS_DRIVE.json`: metadados da versão final lidos do Drive e verificados contra tamanhos locais. Não é alegação de checksum remoto.
- ZIP: snapshot de materiais de aprovação, não pacote de instalação ou release do aplicativo.

Os nomes com 2026-11-16 identificam a rodada que começou nessa data; há gravações posteriores à meia-noite UTC de 17/11. Datas reais constam dos recibos. Atualizações de bytes usam os mesmos IDs, sem alterar compartilhamento.

A referência é aprovada; a aparência atual é rejeitada; as duas propostas novas aguardam aprovação. Backup não significa aprovação ou implementação.
